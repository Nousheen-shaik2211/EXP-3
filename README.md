# EXP-3
# Experiment 3: Iterative Prompt Refinement

## Aim
To demonstrate how iterative prompt refinement improves explanations generated by a large language model.

## Problem Statement
Explain photosynthesis to a 10-year-old by comparing a baseline prompt with two refined prompts.

## Technologies
- Python
- Google Gemini API
- Google GenAI SDK
- Google Colab

## Procedure
1. Connect to the Gemini API.
2. Send a baseline prompt.
3. Refine the prompt with an analogy and sentence limit.
4. Further refine it with a memory trick and diagram description.
5. Display and save all responses.
6. Compare the results.

## Installation
```bash
pip install -r requirements.txt
```

## Execution
```bash
python experiment3.py
```

Enter a valid Gemini API key when prompted.

## Output
The program prints three iterations, their responses, a short analysis of each refinement, and a final summary. It also saves the results to `experiment3_results.txt`.

## Conclusion
Iterative prompt refinement allows users to add clarity, audience-specific language, memory aids, and visualization instructions to guide model responses.
